# 空间日记

原生模块保留自动时间安排、QQ 空间可见范围、发布记录、删除同步和成功发布后的记忆。

## 图文日记与预览

「日记」页的「图文日记与预览」默认关闭，关闭时完全沿用原有写作和配图流程。
开启后可以分别选择表情包、公开浏览作品的配图，以及主人指定目录中的图片。
表情包来源默认关闭，需主人单独开启；开启后，表情库中从群聊收藏的图片也可能成为空间配图。
本地图库默认关闭、目录为空；不推断日常图片位置，不扫描桌面或聊天图片目录。

先保存设置，再点击「生成预览（不发布）」查看正文、配图、来源和可见范围。
预览不调用 QQ 发布接口、不改日记历史、不写成功记忆、不消耗当天日记次数。
预览不会自动发布；「现在写一篇」和定时写作会重新生成日记。

## 发布前的隐私边界

- 新流程不取聊天流水或私人记忆，只取指定来源中最近 48 小时的公开作品记录。
- 图片备注、作品标题是数据，不是指令；模型只能选择候选编号，不能提供路径或下载地址。
- 本地目录必须由主人明确填写并开启。只放允许自动发布到空间的素材；不会自动识别图片中的人脸、文字或位置隐私。生成预览后请检查画面本身。
- 不穿过目录链接；读取图片前再次检查授权目录。外部图片逐跳检查公网地址，单张不超过 8MB。
- 公开浏览图片注明作品与作者，链接重新构造，不携带登录参数。
- 发布仍走核心 `post()`，保留五种可见范围及好友名单；模型请求不能扩大范围。下载后、实际发布前再次检查最新配置，撤销图文来源授权会中止本次发布。
- 试运行不真发。只有实际成功发布的日记会写入成功记忆。

模型选错配图编号时，保留正文和已匹配的图片，从本轮授权候选中按正文备注匹配重新选图。
候选为空或图片读不到时只跳过配图，不因此拦住整篇日记。提示会说明是编号匹配或图片读取失败，不称为隐私问题。
模型主动不选图时保持纯文字。正文敏感信息检查、可见范围和主人撤销来源授权的检查仍然生效。

敏感文本规则只提供基础拦截，不能代替主人检查正文和图片。关闭新功能后仍是原有聊天摘录流程，适用原有的隐私设置。

核心测试：`node --test test/diary-media.test.js test/qzone.test.js test/qzone-audience.test.js test/diary-image.test.js`。

## 日期归档

这一部分在配图与预览之后单独审阅。

「按日期归档浏览图」默认关闭，输出目录默认留空，必须由主人主动填写。
开启并保存后每五分钟检查一次，也可点击「现在收集浏览图」。只保存已有的公开作品封面和 B 站视频抽帧，单轮最多八张。
按浏览发生时的上海日期保存，例如 `20261031/浏览图-摘要.png`，旁边有同名 `.json` 来源说明。
按来源和内容去重，不覆盖已有图片；失败会显示提示并在下次重试。总开关关闭、试运行开启或下载途中撤销授权时不向归档目录写图片。
归档不会自动发布。需要在日记里使用时，另外主动开启「使用指定目录的图片」，并填写这个归档目录；再次选中归档图仍会注明原作出处。

额外核心测试：`node --test test/diary-archive.test.js`。
