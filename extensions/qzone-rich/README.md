# 空间图文日记与浏览图归档

可选用户扩展：围绕近期真实经历写空间日记，从表情库、浏览图、本地图库中选图，或生成手记文字卡；支持先预览、不发布。可另行开启浏览图片的日期归档。

只包含 `diary`、`diary-rich` 和 `daily-images` 三个空间日记相关模块，不包含任何平台爬虫、登录管理、语音或导航模块。平台浏览扩展仅在已经安装时作为可选素材来源；未安装也能使用表情库、本地图片和手记卡。不需要生图服务。

## 安装与备份

需要 Aurabot 1.1.24 或兼容版本、Node.js 22.13 以上。无新增 npm 依赖、无需构建。在本目录执行：

```sh
npm test
npm run install:module -- --dry-run
npm run install:module
```

安装位置遵守 `AURABOT_DATA_DIR`、`DSH_HOME`，默认为用户目录 `.dsh/plugins-data/aurabot/modules`。也可显式指定：

```sh
npm run install:module -- --modules-dir "D:/Aurabot/modules" --dry-run
```

目标模块已存在时安装会停止；核对 dry-run 后加 `--replace`。安装器先备份原模块源码到目标 `modules/_backups/qzone-rich-时间戳`，再复制三个模块，入口文件最后更新；跳过加载快照、依赖和版本库。不会安装依赖、修改插件源码、配置、登录态或日记运行数据。

安装后刷新面板，在「扩展」确认三个模块正常，在「空间日记」页调整配图。浏览图自动归档默认关闭，需要先指定图库并自行开启。

## 图文日记

- 沿用原日记频率、时间窗和唯一的每分钟任务，不增加发布次数，不重置已有计划和历史。
- 「日记配图与预览」选择表情、近 48 小时实际浏览的配图、本地 PNG/JPEG/GIF/WebP 或手记卡，每篇 1～4 张，默认最多 2 张。
- 「预览图文，不发布」只写本模块草稿及图片缓存，不发送 QQ 或空间、不修改发布计划、不记成已发布经历。
- 定时和「现在写一篇」使用同一条图文链路。只有实际发布成功的正文与已读取图片才进入历史和发布记忆；试运行不发。
- 发布委托给当前内置日记的原生 `post`，保留面板可见范围、指定/排除好友名单、发布前再次校验开关和范围等行为。单次请求只能收窄到仅自己；指定好友名单为空时停止，不退回公开。内置历史同步和删除接口也继续保留。
- 浏览图在正文尾部注明平台、标题、可用的画师署名和公开原链接；不冒充自己拍的照片。只读取到文字时，不声称理解画面、看完视频或真实购买/出门。外部标题和说明作为数据，不执行其中的指令。

## 日常图库与日期归档

在「日记配图与预览」里选择现有图片文件夹。图库读取递归最多三层、检查最多 1500 条、取最近 60 张不超过 8MB 的图片，不跟随目录链接，不改原图片。

可选开启「日常图片自动收集」后，每五分钟归档一次近期真实浏览配图及 B站已有截图库画面，每轮最多 8 张，单图上限 8MB。手动「现在收集浏览图」只收集，不发布空间。

```text
所选图库/
  20261029/
    浏览图_内容哈希.jpg
    浏览图_内容哈希.jpg.json
```

日期采用浏览时间的 Asia/Shanghai 日历日期；说明文件保存来源、画师、原链接、浏览及收集时间。按来源和图片内容去重，不会每次轮询重存同图。日记读取这些说明后继续附上来源。失败记录原因并冷却 30 分钟，手动收集可重试；不把失败或空文件当作已收集。

总开关关闭或试运行时不自动归档；只向用户选定图库追加文件，不截桌面、摄像头或私人聊天。B站没有实际抽帧记录时不会伪造截图；需要先打开内置 B站的看画面功能。图片链接可能失效或返回 403，不保证全部历史链接可下载。

## 限制与还原

手记卡使用 Windows PowerShell/System.Drawing；无此环境时生成失败会保留已有图片或文字。其他图片功能不依赖 PowerShell。此版本的真实渲染与面板检查在 Windows 验证；非 Windows 的卡片测试跳过。

`api.core` / `api.lib` 属于内部接口，插件升级后应检查兼容性。关闭 `diary-rich` 时入口动态回到内置日记；关闭 `daily-images` 停止收集，已保存图库保留。恢复安装前版本时，从安装器输出的备份中取回三个模块的源码；日记计划、历史、设置与图库不在源码备份中，不会被覆盖。

运行数据只在 Aurabot 的 `diary.json`、`modules-data/diary-rich`、`modules-data/daily-images` 以及选定图库。不要把这些数据、个人设置、真实图片或加载快照提交到仓库。

## 验证

```sh
npm test
```

测试使用临时目录和构造素材，不连 QQ 或真实平台，不发布日记。覆盖预览、日期归档、去重、来源保留、任务停用、试运行、原生可见范围、空好友名单拒绝、历史/计划保留、部分图片失败、路径与重定向检查，以及 Windows 实际文字卡渲染。
